# PR VISION HRMS — Practical Developer Manual Testing Checklist

**Date**: 2026-11-16  
**Purpose**: Pre-release interactive browser verification checklist for developers and QA engineers.  
**Important Policy**: Automated backend/frontend tests (`88/88` backend Vitest tests and `49/49` frontend Vitest/RTL tests) have **PASSED**, but interactive browser verification was not executable in the automated agent environment (`DevToolsActivePort` `ENOENT`, no local Playwright/Puppeteer/WebDriver installed). Therefore, all manual browser items below are marked **PENDING** until executed by a human tester in a live browser session.

---

## Pre-Test Setup

1. Start the backend server in one terminal:
   ```bash
   cd server
   npm run dev
   ```
2. Start the frontend Vite server in a second terminal:
   ```bash
   cd client
   npm run dev
   ```
3. Open `http://localhost:5173` in Chrome/Edge with DevTools Network tab open (`Disable cache` unchecked to observe `queryCache` behavior).
